Pages and PDFs

Any Colorbee document can have pages. Open a PDF to redact or mark up every page, or put several screenshots together and export them as one PDF.

Open a PDF

Open it with File ▸ Open… or drag it onto Colorbee. Every page opens at once, as an image.

  • Pages open at the resolution set in Colorbee ▸ Settings ▸ General: 150, 200 (recommended) or 300 DPI. Higher is sharper but uses more memory.
  • A PDF becomes pictures of its pages, so its text, fonts and form fields can't be edited as text. It opens as an untitled copy, and the original PDF is never changed.
  • Multi-page TIFFs and animated GIFs open the same way, one page per frame.

The page sidebar

Once a document has more than one page, the page sidebar shows down the left side. View ▸ Page Sidebar (⌥⌘2) shows or hides it.

  • Click a page to edit it. The Layers panel and the rest show that page.
  • Drag a page to move it. The list scrolls as you drag near its top or bottom.
  • Right-click a page for New Page, Duplicate Page and Delete Page.

The Page menu

CommandWhat it does
New PageA blank page after this one, the same size, filled with Color 2.
Duplicate PageA copy of this page, with its layers, just after it.
Delete PageRemoves this page.
Move Page Up and Move Page DownMoves this page one place.
Previous Page (⌥⌘↑) and Next Page (⌥⌘↓)Shows the page before or after.

Undo on pages

Each page remembers its own changes. ⌘Z undoes the last change on the page you're looking at, and View ▸ History shows only that page's steps. Adding, duplicating, deleting and moving pages can be undone too, when that's the newest thing you did in the document.

Redact a PDF

  • Effects ▸ Auto-Redact… checks every page. The list is grouped by page, and clicking an item shows it. One ⌘Z undoes it on every page.
  • Batch Redact and the Redact Brush work on the page you're looking at.

See Redact a screenshot for the details.

Make a PDF from screenshots

  1. Paste the first screenshot with File ▸ Paste into New Image (⇧⌘V).
  2. Choose Page ▸ New Page, then paste the next screenshot onto it with ⌘V. If it's bigger than the page, Colorbee offers to make the page bigger.
  3. Repeat for each screenshot, then choose File ▸ Export as PDF….

Scan with your iPhone or iPad

With no Colorbee document open, choose File ▸ Import from iPhone or iPad, then your device and Scan Documents or Take Photo. When you finish on the phone, what you scanned opens in Colorbee as a new document, one page per scan.

Your iPhone or iPad needs to be signed in to the same Apple Account as your Mac, with Wi-Fi and Bluetooth on.

Export as PDF

File ▸ Export as PDF… saves every page, in order, as one PDF.

  • Each page is saved as pixels, as you see it. No text hides under a redaction, though it also means the text can't be selected or searched.
  • The file holds no details about who made it or when.
  • Pages from a PDF keep the size they opened at. A screenshot page counts as a Retina screenshot, so a 1440-pixel-wide screenshot makes a 10-inch-wide page.

Other kinds of export (Export…, Export As, Copy, Share and Print) use the page you're looking at. To keep every page for later editing, save the document: it saves as a Colorbee project.
