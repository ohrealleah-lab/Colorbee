Colorbee Help

Pixel art

Every pixel exactly where you put it: a hard-edged pencil, a grid, deep zoom and mirroring.

Start small

  1. Choose File ▸ New, then Image ▸ Canvas Properties… (⌥⌘E) to set a small size, such as 32 × 32. Turn on a transparent background there if you want one.
  2. Zoom in with ⌘=, pinch, or the zoom in the status bar. Colorbee zooms up to 3200%, and pixels always stay crisp squares.
  3. Choose View ▸ Pixel Grid (⌘') to show a line between pixels. It appears at 400% and above.

The Pencil

  • Press P. The Pencil draws one-pixel lines with no soft edges.
  • Left-click draws with Color 1, right-click with Color 2.
  • Hold Shift to keep a line straight across or up and down. This works with the brushes and the Eraser too.
  • Press I for the Eyedropper to pick up a color from the image. Option-click picks from all visible layers together.
  • Press G for Fill. Set its Tolerance to 0% to fill only exactly matching pixels.

Symmetry

Image ▸ Symmetry mirrors what you draw: Vertical (left and right), Horizontal (top and bottom), or Both. A faint guide line shows the mirror. It works with the Pencil, the brushes and the Eraser. The Symmetry switch is also in the status bar.

Swap one color for another

The Color Eraser changes only pixels of one color, and leaves the rest alone:

  1. Set Color 1 to the color to replace and Color 2 to the new color.
  2. Choose the Eraser (E) and right-drag over the area. Only Color 1 pixels change to Color 2.

To use a left-drag instead, turn on Color Eraser in the palette bar. Its Tolerance starts at 0%, an exact match.

Resize without blurring

  • Image ▸ Resize and Skew… (⌘E): choose Sharp (pixel art) so each pixel becomes a clean block. 200%, 400% and so on give the neatest result.
  • When you drag a selection's handles, the palette bar's Resize choice does the same: choose Sharp pixels.
  • File ▸ Export As never makes an image bigger, so to share pixel art larger, use Resize and Skew with Sharp (pixel art) first, then export.

Save it

Save as PNG to keep every pixel and the transparency exactly. JPEG blurs small details, so it isn't a good fit for pixel art.
